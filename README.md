# 🚗 Car Price Prediction using Python + Machine Learning

# 📝 Description
This project predicts car prices using machine learning algorithms based on features like mileage, age, fuel type, and brand

# ⚙️Technologies Used
Python 🐍
Pandas 🐼
Numpy 🔢
Scikit-learn ⚙️

# 📊 Machine Learning Algorithm
📉 Linear Regression

# 📊 Dataset
🚗 cardekho_dataset.csv

# 🔄️ Project Workflow
1.Data Collection
2.Data Cleaning
3.Data Preprocessing
4.Model Training
5.Price Prediction

# 🚀 Setup and Installation
follows these steps to run this project locally on your system:

1. Clone the repository:
```bash
git clone https://github.com
```

2. Navigate to the project directory:
```bash
cd Car_Price_Prediction

3. Install all required dependencies:
```bash
pip install pandas numpy scikit-learn 
```

4. Open `Car_Price_Prediction.ipynb` and execute the cells sequentially.
